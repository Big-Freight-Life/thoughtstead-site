# Start here

Thoughtstead is one connected workspace for deciding how AI changes the work.
It holds the research, the people it affects, the process it touches, the
concept and the system behind it, and the decision about whether it should ship
at all, with each client or company kept apart from the others.

This page is the map. Everything else in these docs hangs off it.

## Getting started

Thoughtstead is a hosted service. There is nothing to install on a server,
nothing to deploy, and no API key to obtain for search and enrichment. The
agent work, including the delivery desk and coach, runs on the Claude Code or
Codex you already use. Sign in and your contexts, defaults, and document categories are
created for you on first sign-in.

From signing in to your first capture is under a minute.

## Contexts

Everything in Thoughtstead lives in a **context**. Business is one. Personal is
another. You can add more — a second company, a side project, a household.

A context is a wall, not a folder. Search in one never returns results from
another, and an agent working in one cannot see into another. That separation
is enforced in the database rather than by you remembering which app you were
supposed to have open, which is what makes it safe to keep your accounts
receivable and your dentist appointments in the same product.

Switch contexts from the context switcher; manage them in
**Settings → Contexts**.

## What lives inside

The design studio holds research notes, a positioning brief, the people and
systems involved, the process as people experience it, concepts as storyboard
and digital twin, the Value Matrix, AI Security, and a gallery of what you show
people. Projects tie it together for a client engagement, with a delivery desk
for what is happening across clients and a coach that checks new work for gaps.
Alongside that sit meetings, decisions, documents,
contracts, proposals, people, and communication (a session recorder, an AI email
composer, and your calendar). All of it gets the same capture, the same semantic
search, and the same agents.

Earlier areas for health, home and auto, warranties, lifestyle, and invoices
have been retired from the navigation. Their data is kept, and you can read and
export it from **Settings → Retired areas**.

## Where you use it

- **The desktop app** is where Thoughtstead works hardest. It records and
  transcribes the meeting you are sitting in, stays in the menu bar a keystroke
  away for a thought you need to get down, and works with the Claude Code or
  Codex you already use. It starts on the Mac, and Windows follows.
- **The web app** has the same workspaces, the same navigation and the same
  features, on any computer with a browser.
- **Your phone** catches whatever happens away from the desk.
