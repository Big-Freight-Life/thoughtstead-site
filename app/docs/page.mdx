# Start here

Welcome to Thoughtstead. This page is the map — everything else in these docs
hangs off it.

## Getting started

Thoughtstead is a hosted service, so there is nothing to install and nothing to
deploy. Sign in and you are in your own brain: your contexts, defaults, and
document categories are all created for you on first sign-in.

There is no setup wizard, no database to verify, and no API key to obtain — AI
usage is included in your subscription.

From signing in to your first captured thought is under a minute.

## Running it yourself

A self-hosted edition — Thoughtstead on your own infrastructure, your own
database, your own keys — ships after the hosted apps. It is not available yet.

The deployment guides below describe how that works and are kept here for
reference, but they are **not usable today**: they assume access to the source,
which is not currently sold.

- [Click-and-go](/docs/click-and-go) — the no-terminal deployment path.
- [Self-deploy](/docs/self-deploy) — the command-line deployment path.
