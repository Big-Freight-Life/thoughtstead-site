# Start here

Thoughtstead is a design environment for AI. It holds what you are building —
the research, the positioning, the concepts, and the decision about whether a
feature should exist at all — alongside the clients and companies you do that
work for, without letting any of them see into the others.

This page is the map. Everything else in these docs hangs off it.

## Getting started

Thoughtstead is a hosted service. There is nothing to install on a server,
nothing to deploy, and no API key to obtain — AI usage is part of the
subscription. Sign in and your contexts, defaults, and document categories are
created for you on first sign-in.

From signing in to your first capture is under a minute.

## Contexts

Everything in Thoughtstead lives in a **context**. Business is one. Design is
another. You can add more — a client, a second company, a side project.
Contexts created before November 2026, Personal and Household among them, keep
working and keep their records.

A context is a wall, not a folder. Search in one never returns results from
another, and an agent working in one cannot see into another. That separation
is enforced in the database rather than by you remembering which app you were
supposed to have open, which is what makes it safe to keep one client's work and
another's in the same product.

Switch contexts from the context switcher; manage them in
**Settings → Contexts**.

## What lives in each

A design context gets the studio: research notes, a positioning brief,
concepts as storyboard and digital twin, the process map, the Value Matrix, the
gallery of what you show people, and the delivery desk for the systems already
shipped. A business context gets clients, contracts, proposals, projects,
meetings, decisions, documents, and people. All of them get the same capture,
the same semantic search, and the same agents. The health, home and auto,
warranty, lifestyle and receivables pages were retired in November 2026; their
data is kept, and readable and exportable in **Settings → Retired areas**.

## Where you use it

- **The Mac app** is the main way in. It does what a browser genuinely cannot:
  record and transcribe the meeting you are sitting in, stay a keystroke away
  for a thought you need to get down, and run the Claude Code or Codex you
  already use inside Thoughtstead, with only Thoughtstead's tools. A Windows
  app follows.
- **The web app** has the same workspaces, navigation and features, and runs on
  any machine you can open a browser on.
- **Your phone** catches whatever happens away from the desk.
