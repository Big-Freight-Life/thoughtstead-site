# Click-and-go deploy

The fastest path from GitHub invite to a running Thoughtstead. No terminal
required.

## Before you start

You'll need three free accounts and one key:

- A free **GitHub** account (you already have this if you accepted the
  invite).
- A free **Vercel** account.
- An **OpenRouter** API key from [openrouter.ai/keys](https://openrouter.ai/keys) —
  this is what pays for embeddings and AI enrichment. A $5 credit lasts
  months at typical personal-use volume.

## Steps

1. **Accept the GitHub invite** if you haven't already (check
   [github.com/notifications](https://github.com/notifications) if the email
   didn't arrive).
2. **Click the Deploy button** in the repository's README on
   `github.com/Big-Freight-Life/thoughtstead`.
3. **If Vercel reports it can't clone the private repo**, don't worry — this
   happens because Vercel's clone flow needs a repo it can read. Use the
   equivalent path instead:
   - On the repo page, click **Use this template → Create a new repository**.
     Make it private, under your own account.
   - Go to [vercel.com/new](https://vercel.com/new) and import your new repo.
4. **Accept the Supabase integration.** Vercel will offer to provision a
   Supabase project for you as part of the deploy — accept it. This creates
   your database automatically; you won't need to touch Supabase directly.
5. **Enter your environment variables when prompted:**
   - `OPENROUTER_API_KEY` — from [openrouter.ai/keys](https://openrouter.ai/keys).
   - `CRON_SECRET` — any long random string you make up. It just needs to be
     unguessable.
6. **Deploy.** It takes about 2 minutes. Database migrations apply
   automatically during the build — you don't run any migration commands
   yourself.
7. **Open your app URL** once the deploy finishes, and create your account.
   The first account created becomes the workspace owner. Follow the setup
   wizard from there — it checks your database, confirms your AI key, and
   offers to connect Gmail, Calendar, and your AI tools.

That's it — from accepted invite to a running Thoughtstead is well under 10
minutes.

## Troubleshooting

**Build fails at `[migrate-deploy]`.** This means the migration runner
couldn't reach a database. Confirm the Supabase integration is actually
attached to your Vercel project, and that `POSTGRES_URL_NON_POOLING` shows up
in the project's environment variables (Vercel adds this automatically when
the Supabase integration is attached — if it's missing, the integration
didn't finish provisioning).

**The app loads, but Connectors says "needs one-time setup."** That's
expected — Gmail and Calendar sync require your own Google OAuth
credentials, which aren't part of the one-click deploy. See
[Gmail & Calendar](/docs/connectors) to finish that part whenever you're
ready; everything else works without it.
