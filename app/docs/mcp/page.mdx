# Connect AI tools

You can let the Claude Code, Codex, Claude app or ChatGPT plan you already pay
for work inside Thoughtstead. It uses your own plan. Thoughtstead never sees
your login for it and never asks for an API key.

Your AI connects through [MCP](https://modelcontextprotocol.io), the protocol
Claude, Codex and a growing list of tools use to read and act on outside data.
It reaches Thoughtstead through tools on our server, and only those tools.

## What it may do

Nothing is shared until you approve the connection in **Settings → MCP**. You
choose one of four levels:

- **Read your memory.** The AI can search and read.
- **Read and add to your memory.** It can also save thoughts.
- **Work in this workspace.** It can also create and edit projects. Anything that
  deletes, sends, assigns, or ends a role waits for your approval in Approvals.
- **Build one client's ontology.** The AI sees only that one ontology and that
  client's own thoughts, documents, and meetings, and nothing else in your
  workspace. It cannot change anything itself: every edit it proposes waits on
  the Object Model page for you to approve or reject.

Each connection has two daily limits that reset at 00:00 UTC: 200 writes and 500
reads. You can revoke a connection at any time in Settings, and it stops working
straight away.

## Connect Claude Code

```bash
claude mcp add --transport http thoughtstead https://app.thoughtstead.com/api/mcp/mcp
```

Then start `claude`, run `/mcp`, and follow the browser sign-in. Add
`--scope user` to the first command to use it in every project.

## Connect the Claude app or claude.ai

Open Customize, then Connectors, then **+ Add**, then Add custom connector. Enter
a name and the same address, continue, and sign in. On Team and Enterprise plans,
an owner adds the connector under Organization settings, and members then click
Connect.

## Connect Codex

Add this to `~/.codex/config.toml`:

```toml
[mcp_servers.thoughtstead]
url = "https://app.thoughtstead.com/api/mcp/mcp"
```

Then run `codex mcp login thoughtstead` and sign in. In the Codex desktop app or
IDE extension, choose Authenticate instead.

## Finish

After you sign in, the connection appears in **Settings → MCP**, waiting for your
approval. Pick a level and approve it.
